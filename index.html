Task Tracker Watch

A personal, single-device smartwatch project.

Task Tracker Watch is a hobby project: custom firmware running on an ESP32-S3 smartwatch that I built and use myself. It shows a task and event list synced from a single personal Google Calendar, alongside a watch face.

This is not a commercial app, is not distributed to other users, and has no companion mobile or web app. It exists solely so that this one device can read my own calendar.

See the privacy policy for details on what data this project accesses and how it is handled.
