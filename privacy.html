Privacy Policy

Last updated: [September 29, 2026]

Task Tracker Watch is a personal, non-commercial hobby project: custom firmware on a single ESP32-S3 smartwatch device that I built and use myself. It is not distributed to other users. This policy explains what data it accesses and how that data is handled.

What data this project accesses

The watch connects to Google Calendar using OAuth 2.0, with read-only access to calendar events (the app requests no write, sharing, or modification permissions on your calendar).

Where data is stored

The OAuth refresh token and synced calendar event data are stored only on the watch's own on-device flash storage (NVS). Nothing is uploaded to any server other than Google's own Calendar API, which the watch contacts directly to fetch event data.

Data sharing

No data is shared with, sold to, or processed by any third party. There is no analytics, advertising, or tracking of any kind in this project.

Data retention and deletion

Calendar data and the stored authorization token remain on the device until it is reflashed or factory reset, at which point they are erased. You can revoke this app's access at any time from your Google Account permissions page.
